# CAA 版实施路线（形状级对称）

## 阶段 0：前置条件（当前卡在这里）

| 需要 | 现状 | 谁来做 |
| --- | --- | --- |
| CAA RADE V5R20（win_b64），含 `intel_a\code\bin` 工具链 | ❌ 未安装 | 用户/IT/代理商（需 Dassault 账号与 CAA 许可） |
| Visual Studio 2005 或 2008（VC8/VC9）含 x64 工具链 | ❌ 未安装 | 同上 |
| 目标 CATIA 具备加载自定义 CAA 工作台的许可 | ❓ 待确认 | 必须提前确认，否则无法部署运行 |

**在这三项到位之前，任何 CAA 代码都无法编译，更无法在 CATIA 里运行。**

## 阶段 1：可编可跑的最小命令（RADE 到位后 1~2 天）

1. 用 `CATCommand` + `CATDlgDialog` 建一个命令「对称倒圆角助手」；
2. 取当前 Part 的 `CATBody`（`CATIPrtPart`/`CATIPrtContainer` → `CATBody`）；
3. 用 `SymmetryFinder::EnumerateAllEdges` 验证"能枚举到当前实体全部边"（关键里程碑）；
4. 把边的数量、长度打印到对话框，确认形状变化后仍然枚举正确（做完一次圆角再枚举一次）。

## 阶段 2：几何匹配（1~2 天）

5. 取选中边 → `SampleEdge` → 用 `CATMathTransformation::CreateReflection` 镜像；
6. 遍历枚举出的边做双向点集匹配（容差 1e-3 mm）；
7. 命中后高亮 + 在对话框列出"对称边（误差 xx mm）"。

## 阶段 3：一键倒圆角 + 形状级连续作业（1~2 天）

8. 用 `CATIPrtShapeFactory`（或 `ShapeFactory` 的 CAA 接口）对两条边一次性生成 `EdgeFillet`；
9. 支持"一次把其余所有对称位置都倒上"（批量匹配 + 批量生成，仍是 1 个圆角特征 + 1 个镜像/阵列特征）；
10. 每完成一刀，重新枚举实体 → 于是"圆角之后的新形状"也能继续找对称边（**这正是你要的能力**）。

## 阶段 4：打包与部署

11. 生成 `.dll` + 资源 + 环境文件，用 CAA 的部署流程装到目标机；
12. 目标机 CATIA 需具备加载自定义工作台的许可（阶段 0 已确认）；
13. 与现有便携版助手共存：日常用助手，形状级对称用 CAA 命令。

## 与现有自动化助手的边界（避免重复劳动）

* 自动化助手：草图类边、无编译、免安装、任意 CATIA 版本可试；
* CAA 版：任意边（含圆角/阵列/布尔之后的新边）、纯几何匹配、需要 RADE 与许可。

两者**不是替代关系**：自动化版本继续承担"日常快速倒圆角"，CAA 版负责"形状级对称"。
