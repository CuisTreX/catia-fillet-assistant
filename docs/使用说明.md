# 使用说明

## 1. 运行

| 操作 | 说明 |
| --- | --- |
| `安装环境.bat` | 首次运行：在 `D:\Programs\CodexTools\catia-fillet-assistant\venv` 建虚拟环境并装 `pywin32`、`comtypes` |
| `启动助手.bat` | 后台启动助手（pythonw，无控制台窗口）。CATIA 可以先行或后启动，助手会自动重连 |
| `诊断.bat` | 打印当前 CATIA 版本、活动文档、选择集内容、倒圆角对话框状态，排查问题用 |
| `Ctrl+Alt+Q` | 退出助手 |

启动成功时右上角会弹一条"已启动"提示。之后助手常驻后台，占用很小（轮询默认 0.25 秒一次）。

## 2. 选到面提醒

1. 在 CATIA 里打开「边线倒圆角」（图标或 `Ctrl+Alt+F`）。
2. 只要你选进来的东西**不是边线**（面、datum 平面、点等），右上角立刻弹出红色提醒，写明选到了什么。
3. 点「移除误选」即可把误选元素从选择集里删掉，然后重新点边线即可。

判定依据（都来自 CATIA 自动化，和界面语言无关）：

* `SelectedElement.Reference.DisplayName` 的 `REdge:` / `RSur:` 前缀；
* 手动拾取时对象类型名（`TriDimFeatEdge` = 边，`PlanarFace`/`CylindricalFace` = 面）；
* 官方推荐的 `Selection.FilterCorrespondence(["TriDimFeatEdge"])`。

## 3. 右键补对称边线（v0.3 起：直接出圆角）

### 推荐用法（最快）

1. 在模型上**点选一条边线**（不用管倒圆角命令是否开着）。
2. 按**鼠标右键**（或 `Ctrl+Alt+R`）。
3. 助手算出对称的那条边线，并**直接用官方 API 生成倒圆角**：
   * 半径优先取「倒圆角定义」对话框里你填的值；对话框没开就用 `config.json` 的 `fillet_radius`（默认 5）；
   * 如果有不止一种对称解释，会弹出让你选「关于X法向的中面镜像 / 关于Y法向的中面镜像 / 绕Z轴旋转180°」等；
   * 右键会被接管（不弹 CATIA 右键菜单）；想只补到选择集、不生成圆角，把 `symmetric_action` 改成 `"select"`。

### 已经开着倒圆角对话框时

1. 在对话框里点一条边线（此时对话框里会显示形如 `凸台.1\目标边线.1`）。
2. 按**鼠标右键**（或 `Ctrl+Alt+R`）。
3. 助手从对话框列表读到这条边 → 量出它的几何 → 算出对称边 → **先关掉这个对话框**（避免留下未完成的特征）→ 直接生成对称倒圆角。

> 为什么不是"往对话框里再塞一条边"？
> 实测（V5R20）：CATIA 的交互式倒圆角命令**只认手动点选的对象**，
> 宏/自动化加进去的引用命令不认（对话框列表仍是空的、按确定也不生效）；
> 而且命令运行中点选的对象不会出现在 `Document.Selection` 里。
> 所以助手改成"读到你的点选 → 自己按官方 API 把两条边一起倒圆角"，
> 结果和你在对话框里点两次是一样的，而且不会因为选错对象而失败。

### 想保留 CATIA 原生右键菜单

把 `config.json` 的 `rmb_mode` 设为 `"dialog"`（只有倒圆角对话框打开时才接管右键），
或 `"off"`（完全不接管，只用热键 `Ctrl+Alt+R`）。

对称是怎么算出来的：

* 零件重心（`Measurable.GetCOG`，取不到时退回草图包围盒中心）作为对称中心；
* 两条途径：
  * **标签法**（边线已在文档选择集里）：从 GenericNaming 标签读出它由哪几条草图元素生成 → 做镜像/旋转映射 → 序号代回标签 → `CreateReferenceFromBRepName`；
  * **几何法**（命令里手动点选的边）：从对话框列表拿到单元名 → `FindObjectByName` + `Measurable` 拿到 3D 采样点 →
    按"生成它的特征（凸台/凹槽）的草图 + 拉伸参数"算出这个特征所有候选边的几何 → 用几何把点选那条边和候选对上 →
    对候选做镜像/旋转 → 找到对称那条边的标签。
* 最后用官方 API 生成圆角：
  `ShapeFactory.AddNewEdgeFilletWithConstantRadius(边1, 传播方式, 半径)` + `AddObjectToFillet(边2)` + `Part.Update()`。

可以在 `config.json` 里固定对称方式（避免每次选择）：

```json
{
  "symmetry_mode": "mirror",   // auto | mirror | rotate | off
  "mirror_axis": "y",           // 关于 Y 法向、过重心的中面镜像
  "rotate_axis": "z",
  "rotate_angle": 180.0,
  "tolerance": 0.01,
  "right_click_pairing": true,
  "rmb_mode": "any",              // any=选中边线就接管右键 | dialog=仅倒圆角对话框内 | off=不接管
  "symmetric_action": "fillet",   // fillet=直接生成倒圆角（推荐）| select=只把对称边加进选择集
  "fillet_radius": 5.0,           // 对话框没开时用的半径（对话框开着时优先用对话框里的值）
  "fillet_propagation": 1,        // 0=不传播 1=相切连续
  "auto_remove_wrong_pick": false,
  "poll_interval": 0.25,
  "hotkey_pair": "ctrl+alt+r",
  "hotkey_remove_wrong": "ctrl+alt+x",
  "hotkey_start_fillet": "ctrl+alt+f",
  "hotkey_quit": "ctrl+alt+q",
  "extra_dialog_titles": []
}
```

## 3.5 形状级对称（v0.5.0 起：圆角/阵列/布尔之后的新边也能用）

上面的"草图法"只认由草图元素生成的边。**形状级对称**不看草图，只看当前实体的几何：

1. 打开倒圆角对话框，点**一条**边（圆角之后新生成的圆弧边、阵列出来的边、布尔之后的边都行）；
2. 按**鼠标右键**或 `Ctrl+Alt+R`；
3. 助手会：

```text
把当前实体的所有边扫出来（含圆角/阵列/布尔后的新边）
   ↓ 用几何识别镜像面（包围盒中面 / 主惯性面 / 由候选边反推）
   ↓ 把你的那条边镜像过去，在所有边里找最贴合的一条
   ↓ 位置 + 长度 + 半径 + 方向 + 到中心距离 一起判（绝不是"中点接近就算"）
   ↓ 唯一高分 → 直接生成 1 个含两条边的倒圆角
        多解     → 弹选择框（显示中点/长度/类型/匹配度，你点哪个用哪个）
        找不到   → 明确告诉你"未找到高置信度的轴对称边"，绝不乱配
```

几个会遇到的提示，以及它们的意思：

| 提示 | 含义 | 你要做什么 |
| --- | --- | --- |
| 已生成对称倒圆角 | 找到唯一镜像边并建好了一个倒圆角（特征树只多 1 个） | 完事 |
| 选择对称边（弹选择框） | 有 2 条以上同样合理的镜像边（例如矩形板上一条角边，既可左右镜像也可上下镜像） | 点你要的那条 |
| 这条边在对称面上 | 这条边镜像后还是它自己（垂直于/落在对称面上），没有"另一条" | 直接对它倒圆角即可 |
| 未找到对称边 | 这个形状在该位置没有可信的镜像关系（不对称件就是这样） | 手动点你要的那条边 |
| 生成倒圆角失败…（已清理 N 个未完成的特征） | CATIA 拒绝了这个位置（多半和已有圆角几何冲突），助手已把半成品删干净 | 换一条边再试 |

配套开关（`config.json`）：

```json
{
  "shape_engine_enabled": true,      // 形状级对称总开关
  "shape_engine_first": false,       // true=优先形状引擎；false=先草图引擎、失败再形状引擎
  "shape_engine_autocreate": true,   // false=只提示对称边位置，不自动建特征
  "shape_tolerance": 0.05,           // 位置容差（mm）
  "shape_min_score": 0.72,           // 接受分数下限（越高越保守）
  "shape_score_margin": 0.06,        // 与第二名的差距（不够大就弹选择框）
  "shape_plane_min_ratio": 0.7,      // 镜像面整体匹配率下限
  "shape_max_planes_try": 2,         // 一次动作最多评估几个镜像面（越大越慢；多解时仍会继续评估）
  "shape_scan_restore_selection": true,  // 扫完把原来的选择集还回去（关掉会留下整圈高亮）
  "shape_manual_fillet_max_edges": 4,    // "手动选中多条边一次做圆角"最多几条（防误选整圈）
  "shape_edge_queries": []           // 旧版本 CATIA 搜索语法不同时在这里补
}
```

> **v0.5.1 手感优化**：以前每做完一次动作，整圈边线会被留在选择集里（视图全红、CATIA 变慢），
> 现在扫描结束会把原来的选择集还原，动作完成后清空选择集；
> 镜像面评分也加了廉价预过滤（先用长度/中点排除不可能的配对）+ 提前退出，
> 36 条边的零件上一次动作从约 9 秒降到约 2.5 秒。

> 实测（V5R20）：100×60×40 凸台两条竖边 R5 → 体积 240000 → 239570.8 mm³；
> 第一刀之后再选新生成的圆弧边 → 第二刀成功；连续第三刀成功；
> 真正不对称的台阶件逐条边试 → 20 次明确拒绝、4 次"边自身在对称面上"、0 次乱配。

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 启动时提示"找不到运行环境" | 先运行 `安装环境.bat`（需要 Python 在 PATH 里） |
| 热键没反应 | 热键可能被别的软件占用；改 `config.json` 里的 `hotkey_*`，或在日志里看"注册失败" |
| 右键没补边线 | 必须满足：CATIA 在前台、倒圆角对话框打开、当前选中的都是边线 |
| 提示"暂不支持" | 这条边不是由草图元素生成的（例如由圆角/阵列/曲面生成的边），需要手工点选 |
| 对话框没被识别 | 你的 CATIA 语言版本标题不同：把标题追加到 `config.json` 的 `extra_dialog_titles` |
| 想彻底卸载 | 删掉 `D:\Programs\CodexTools\catia-fillet-assistant`（venv）和本项目目录即可，不写注册表、不改 CATIA 设置 |

日志在 `logs\assistant.log`，出问题时把这个文件发出来即可定位。

## 6. 退出与卸载（v0.3.0 起）

| 入口 | 位置 | 说明 |
| --- | --- | --- |
| 退出助手 | 包里的「退出助手.bat」/「退出助手.lnk」；或 CATIA 里按 `Ctrl+Alt+Q` | 通知正在运行的助手优雅退出（先写退出信号，8 秒没响应才强制结束进程） |
| 卸载 | 包里的「卸载助手.bat」/「卸载助手.lnk」 | **两次确认**后：退出助手 → 删除程序目录 → 删除 `%LOCALAPPDATA%\CatiaFilletAssistant`（日志/配置） |
| 静默卸载（脚本） | `CatiaFilletAssistant.exe --uninstall --yes` | 跳过确认，供批量部署/自动化使用 |

卸载不会动 CATIA 本身（不写注册表、不改 CATIA 设置）。删除程序目录时因为 exe 正在运行，
助手会先把自身改名挪到同级目录，再用一个临时脚本在几秒后清理掉它。

## 7. v0.3.0 修的两个实际问题（来自你的日志）

| 现场 | 原因 | 修法 |
| --- | --- | --- |
| 对话框里选了边线却提示"读不到几何" | 对话框里的单元名是命令内部名（`目标边线.1`），量不到几何 | 现在会用序号试出标准名（`边线.1`/`Edge.1`/`面.1`…）并逐个验证可量测性 |
