# 便携版部署说明（拷过去就能用）

## 1. 拿哪个包

`dist\` 下有版本化命名的包，**任选一个**，整个文件夹拷走（旧的 v0.1 包可删）：

| 包 | 大小 | 适用场景 |
| --- | --- | --- |
| `dist\CATIA倒圆角助手-便携版-v0.3.0\` | 约 16 MB | 首选，只有一个 exe，最省事 |
| `dist\CATIA倒圆角助手-文件夹模式-v0.3.0\` | 约 33 MB | 封闭平台禁止 exe 从临时目录运行时用（onefile 会自解压到 `%TEMP%`；文件夹模式不落地临时目录） |

包里包含（已经自带 Python 3.13、pywin32、comtypes、Tk，**目标机器不需要装 Python，也不需要联网**）：

```
CatiaFilletAssistant.exe        主程序（单文件版=一个 exe；文件夹模式=exe + _internal 目录）
config.json                     配置（热键、对称方式、catia_bin、对话框标题等）
启动助手.bat / 双击这里启动助手.lnk   双击启动
诊断.bat                        自检：生成并弹窗显示诊断报告
使用说明.txt                     一页说明（记事本可读）
```

## 2. 目标机器需要什么

必须满足：

* Windows（64 位；本包内是 64 位 Python，**32 位 CATIA 不适用**）；
* 目标机器上装了 CATIA V5（版本不限，但要能正常起动）；
* 当前用户对 CATIA 有可用的许可证（助手本身不需要许可证，它只是驱动你已打开的 CATIA）。

不需要：Python、pip、联网、管理员权限、注册表写入、CATIA 设置改动。

## 3. 三步用起来

```
1. 把文件夹拷到目标机器（例如 D:\Tools\CATIA倒圆角助手-便携版\）
2. 先双击「诊断.bat」自检（见下一节），确认各项 OK
3. 双击「CatiaFilletAssistant.exe」（或「启动助手.bat」）→ 右上角弹"已启动"即可
```

退出：在 CATIA 里按 `Ctrl+Alt+Q`（不要用任务管理器强杀，避免残留）。
重复双击不会起两个实例（第二个会提示"已在运行"并自动退出）。

## 4. 自检：诊断.bat 看什么

双击后会在包里生成 `诊断报告.txt` 并弹窗显示，重点看这几行：

| 报告行 | 期望 | 不对时怎么办 |
| --- | --- | --- |
| `冻结 exe : 是` | 是 | 说明你在跑便携版，正常 |
| `可写数据目录` | 包所在目录（或 `%LOCALAPPDATA%\CatiaFilletAssistant`） | 若显示 LOCALAPPDATA，说明包目录只读，配置/日志会写到那里，功能不受影响 |
| `CATIA 类型库目录` | 类似 `D:\Programs\CATIA\win_b64\code\bin` | 若定位失败/缺失，改 `config.json` 的 `catia_bin` 指到实际目录 |
| `[必需] InfTypeLib.tlb / MecModTypeLib.tlb` | 找到 | 缺失说明 `catia_bin` 指错目录 |
| `类型库加载 ... OK` | 三行都 OK | 这行失败说明 comtypes 生成接口有问题（把报告发回来） |
| `CATIA 连接 : OK` | OK | 失败一般是 CATIA 没打开；助手不会自己启动 CATIA |
| `倒圆角对话框` | 打开倒圆角命令后显示标题（如"倒圆角定义"） | 显示"未打开"但你确实开着对话框 → 把标题加到 `config.json` 的 `extra_dialog_titles` |
| 选择集列表 | 每条注明"边线/面" | 若边线被判成"未知"，把报告发回来（不同版本类型名可能不同） |

**建议的自检动作**：CATIA 里打开一张零件 → 双击一条边 → 再双击一个面 → 重新跑一次 `诊断.bat`，
对比报告里两条选择项的判定（应为"边线"和"面"）。

## 5. 封闭平台常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 双击 exe 没反应、或提示被安全策略阻止 | 换「文件夹模式」包；若仍被拦，请让 IT 给 exe 加白名单（本程序不联网、不写注册表） |
| SmartScreen 提示"未知发布者" | 未签名程序正常提示，点"更多信息 → 仍要运行"；无法点就换文件夹模式或加白名单 |
| 热键没反应 | 目标机器上 `Ctrl+Alt+R/X/F/Q` 可能被别的软件占用：改 `config.json` 的 `hotkey_*` |
| 右键没补线 | 必须满足：CATIA 在前台 + 倒圆角对话框已打开 + 当前选中的都是边线 |
| 杀软报"鼠标钩子" | 本程序用全局右键钩子实现"右键补对称边线"，如被拦，可把 `right_click_pairing` 设为 `false`，改用热键 `Ctrl+Alt+R` |
| 拷到 U 盘/只读共享盘运行 | 可用；配置与日志会自动写到 `%LOCALAPPDATA%\CatiaFilletAssistant\` |
| 想换 CATIA 版本测试 | 直接在同一台机器上跑；多版本共存时用 `config.json` 的 `catia_bin` 指定要用的那套类型库 |

## 6. 配置文件说明（config.json）

```json
{
  "symmetry_mode": "auto",      // auto 多种对称时弹窗让你选；mirror 只用镜像；rotate 只用旋转；off 关闭
  "mirror_axis": "x",           // 镜像：关于过零件重心的中面，法向轴 x/y/z
  "rotate_axis": "z",
  "rotate_angle": 180.0,
  "tolerance": 0.01,            // 草图元素匹配容差（mm）
  "right_click_pairing": true,  // 右键补对称边线
  "rmb_mode": "any",            // any=选中边线就接管右键 | dialog=仅倒圆角对话框内 | off=不接管
  "symmetric_action": "fillet", // fillet=直接生成倒圆角（推荐）| select=只把对称边加进选择集
  "fillet_radius": 5.0,         // 对话框没开时用的半径（对话框开着时优先用对话框里的值）
  "fillet_propagation": 1,      // 0=不传播 1=相切连续
  "auto_remove_wrong_pick": false,   // 选到面时是否自动移除（默认只提醒）
  "poll_interval": 0.25,        // 监视轮询间隔（秒）
  "hotkey_pair": "ctrl+alt+r",
  "hotkey_remove_wrong": "ctrl+alt+x",
  "hotkey_start_fillet": "ctrl+alt+f",
  "hotkey_quit": "ctrl+alt+q",
  "extra_dialog_titles": [],    // 追加你机器上的倒圆角对话框标题
  "catia_bin": "",              // 留空=自动探测；也可写 "D:\\Programs\\CATIA\\win_b64\\code\\bin"
  "log_level": "INFO"
}
```

改完保存，重启助手生效（`Ctrl+Alt+Q` 退出后重新双击 exe）。

## 7. 卸载 / 清理

* 直接删掉整个文件夹；
* 若日志写到了用户目录，可一并删除 `%LOCALAPPDATA%\CatiaFilletAssistant\`；
* 不写注册表、不改 CATIA 设置/环境变量，删除后无残留。

## 8. 重新打包（换电脑/改代码后）

打包机上执行：

```
双击 打包便携版.bat
或： D:\Programs\CodexTools\catia-fillet-assistant\venv\Scripts\python.exe tools\build_portable.py
```

产物在 `dist\`。打包机需要 Python 3.13 + 网络（装 PyInstaller）；**目标机器不需要**。
