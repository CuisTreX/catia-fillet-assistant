# R5/R14「形状级对称」设计与实现（v0.5.0）

> 一句话：**不再靠草图编号猜，而是把"当前实体的所有边"量出来，用几何找镜像边，
> 再用扫到的真实 Reference 直接生成一个含两条边的倒圆角。**
> 实测结论见 [R5可行性实测-20260925.md](R5可行性实测-20260925.md)。

## 1. 为什么能做（实测前提）

| 事实 | 数据 |
| --- | --- |
| 能枚举当前实体全部边 | `Selection.Add(MainBody)` + `Search("Topology.CGMEdge,sel")` → 100×60×40 凸台得到 **12 条** |
| 枚举结果带真实 Reference | `Selection_REdge:(Edge:(Face:(Brp:(Pad.1;0:(Brp:(Sketch.1;4)))…` |
| 能量几何 | Length（60/100/40）、Radius（圆弧 = 5.0）、GetDirection（单位向量） |
| 圆角新边也能扫到 | 倒圆角后扫描到 4 条 `TriDimFeatEdge`，长度 7.853982 = πR/2（R5） |
| 扫到的 Reference 能当 Fillet 输入 | 直接 `AddNewEdgeFilletWithConstantRadius` → `倒圆角.1` 含 2 条边 |

## 2. 代码结构（新增 3 个模块，不动老逻辑）

```text
src/catia_fillet_assistant/
    edge_scan.py        # 枚举 + 过滤 + 指纹（只读）；采样残缺的直线用「端点+方向+长度」补全
    shape_symmetry.py   # 纯数学：镜像、自对称、平面识别（包围盒/主惯性/由候选反推）、匹配评分、决策
    shape_engine.py     # 编排：源边识别 → 平面 → 候选 → 安全校验 → 生成一个倒圆角
    app.py              # 对话框路径 / 选择集路径接入 + 气泡选择框 + 诊断扩展
    pairing.py          # 生成倒圆角（共用）；新增"失败即清理半成品特征"
```

## 3. 流程

```text
用户在倒圆角对话框里点了 1 条边（或只选中 1 条边）
        ↓ 读对话框半径 / 读选择集
  源边几何指纹（长度 + 采样点 + 半径 + 方向）            ← edge_scan
        ↓
  扫描当前实体全部三维边（过滤草图/线框单元）            ← edge_scan
        ↓
  在扫描结果里认出"用户点的那条"（长度 + 位置）          ← shape_engine.resolve_source
        ↓
  候选镜像面排序：包围盒中面 → 主惯性面 → 由候选边反推   ← shape_symmetry.rank_planes
        ↓ 整体匹配率 ≥ shape_plane_min_ratio（默认 0.7）
        ↓ 连续多刀后整体可能已不对称 → 允许"局部解释"
        ↓ （匹配率 ≥ 0.6、支撑边 ≥ 3、源边镜像误差 ≤ 2×容差）
  逐平面算候选：位置/长度/半径/方向/子段重叠             ← shape_symmetry.rank_candidates
        ↓ 安全阀：类型相容、到对称中心距离一致
  唯一且高分 → 直接生成；多解 → 弹选择框；找不到 → 明确说"没有"
        ↓
  先读半径 → 关命令 → 用扫到的两条 Reference 生成 1 个倒圆角 → Part.Update → 体积自检
```

## 4. 实测验收（tools/test_r5_shape_engine_live.py，全部在临时件上）

| 用例 | 结果 |
| --- | --- |
| Case 1：100×60×40 凸台，选 40 长竖边 | 扫到 12 条边；识别出 X=50 / Y=30 两个合法镜像面 → `AMBIGUOUS`（**不盲选**）；按 Y=30 生成 `倒圆角.1`（2 条边），体积 240000 → **239570.8 mm³**（与理论值一致） |
| Case 3：第一刀之后选圆弧新边 | 圆角后扫到 18 条边（含 4 条 R5 圆弧）；圆弧找到镜像圆弧 → `倒圆角.2` |
| Case 4/5：连续第三刀 | 换边重试后成功 `倒圆角.3`（55 长边对，关于 Z=20 镜像）；与已有圆角冲突的尝试被 CATIA 拒绝并**自动清理**，特征树保持 `凸台.1 + 3 个倒圆角` |
| 负测试：真正不对称的台阶件（24 条边） | 逐条边全部试过：**20 次 `NO_CONFIDENT_SYMMETRY` + 4 次 `SELF_SYMMETRIC`，0 次乱配** |

日志：`docs/API探测/test_r5_shape_engine_live.log`、`docs/API探测/r5_shape_engine_*.json`。

## 5. 三条实测教训（都写进代码了）

1. **自对称边**：垂直于/落在镜像面上的边，镜像后是自己 → 必须先判，否则必然误判。
2. **采样会残缺**：`GetPointsOnCurve` 最多给 3 点（起点/中点/终点），个别边只给 2 点（只覆盖半条边）；
   边的 `GetCOG/GetCenter` 在 V5R20 上"尚未实现"，但 `GetDirection` 可靠 →
   直线用「端点 + 方向 + 长度」重建，圆弧用 `Radius` + 采样点。
3. **前几刀会破坏整体对称**：既不能要求"整零件对称"，也不能只信两条边的巧合；
   采用"整体匹配率 + 支撑边数 + 源边镜像误差"三重门槛（可配置）。

## 6. 配置（config.json，全部可改，不写死）

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `shape_engine_enabled` | true | 形状级对称总开关 |
| `shape_engine_first` | false | 优先用形状引擎（默认先草图引擎、失败再交给形状引擎） |
| `shape_engine_autocreate` | true | 唯一高分候选时直接生成倒圆角；false = 只提示位置 |
| `shape_tolerance` | 0.05 | 位置容差（mm） |
| `shape_length_tol_ratio` / `shape_radius_tol_ratio` | 0.02 | 长度/半径相对容差 |
| `shape_overlap_min` / `shape_allow_subsegment` | 0.7 / true | 被圆角削短的"子段匹配" |
| `shape_min_score` / `shape_score_margin` | 0.72 / 0.06 | 接受阈值与"多解"判定（低于差距就弹选择框） |
| `shape_plane_min_ratio` | 0.7 | 镜像面整体匹配率下限 |
| `shape_plane_min_ratio_local` / `shape_min_local_pairs` | 0.6 / 3 | 连续多刀后的"局部解释"门槛 |
| `shape_max_edges` / `shape_cache_seconds` | 600 / 6.0 | 扫描上限与缓存（生成特征后立即失效） |
| `shape_max_planes_try` | 2 | 一次动作最多评估几个镜像面（多解时仍会继续评估其余强平面，保证"不替你猜"） |
| `shape_scan_restore_selection` | true | 扫完把用户原来的选择集原样还回去（否则会留下整圈高亮、越用越卡） |
| `shape_manual_fillet_max_edges` | 4 | "手动选中多条边一次做圆角"最多接受几条（防止误把整圈边当成你的选择） |
| `shape_edge_queries` | [] | 旧版本 CATIA 搜索语法不同时在这里补（如 `"Topology.CGMEdge,all"`） |
| `shape_weight_*` | 0.40/0.20/0.25/0.15 | 位置/长度/几何/拓扑 权重（自动化拿不到相邻面，拓扑项记中性） |

## 7. 已知限制（不吹）

### 7.1 v0.5.1 性能与手感（用户实测反馈驱动）

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 做过几次后，每次选线整圈边线变红、越来越卡 | 扫描必须把整条边集放进 CATIA 选择集才能读，读完没还原 | `EdgeScanner` 扫描前快照选择集、扫描后原样还原；生成特征后清空选择集 |
| 一次动作等 ~10 秒 | 8 个候选平面对 44 条边做全两两贴合计算（1.5 万次曲线距离） | ① 先用"长度 + 镜像中点"做必要条件预过滤；② 匹配用缓存的按弧长重采样点；③ 加"强平面唯一候选"提前退出；④ 单条边少打 4 次 COM（`GetCOG/GetCenter` 未实现只试一次） |
| 一次动作实测 | 扫描 1.2s + 评分 9.1s | **扫描 0.77s + 配对 2.55s**（36 条边台阶件；`tools/test_r5_perf_live.py`） |

* **相邻面拓扑**这条判据暂时没用上：Automation 拿不到"边 → 两侧面"的对应关系（CAA 才有）。
  当前用"位置 + 长度 + 半径 + 方向 + 中心距离"代替，已通过上面全部验收。
* 圆弧只用 `Radius` + 3 个采样点（`GetCenter/GetAxis` 在边线上不可用），同半径圆弧靠位置区分。
* 与已有圆角**几何冲突**的第三刀会被 CATIA 拒绝：助手会清理半成品特征并提示，不会留废特征。
* 搜索语法 `Topology.CGMEdge` 只在 V5R20 实测过；旧版本若不同，改 `shape_edge_queries`，
  诊断报告会打印实际使用的语法与命中条数。
