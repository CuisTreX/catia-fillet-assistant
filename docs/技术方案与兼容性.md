# 技术方案与兼容性

## 1. 为什么不用 CAA RADE

真正"在 CATIA 原生右键菜单里加命令"需要 CAA RADE 二次开发环境（C++、编译器、CATIA 版本匹配的 RADE 授权），
而且每次 CATIA 升级都要重编译。本机没有 RADE，这条路成本高、交付慢。

本插件走**自动化 + Win32** 路线：

| 能力 | 实现手段 |
| --- | --- |
| 识别倒圆角命令 | 枚举 CNEXT.exe 的顶层窗口 + 标题/控件判定（多语言可配置） |
| 判断选中的是边还是面 | `SelectedElement.Reference.DisplayName`（`REdge:` / `RSur:`）+ 拾取对象类型名 + `FilterCorrespondence` |
| 补对称边线 | 解析 GenericNaming 标签 → 草图元素对称映射 → `Part.CreateReferenceFromBRepName` → `Selection.Add` |
| 右键触发 | 全局低级鼠标钩子（`WH_MOUSE_LL`），条件满足时拦截这次右击并异步执行 |
| 弹提醒 | Tkinter 置顶无边框气泡（非模态，不打断 CATIA） |

## 2. 关键实测结论（本机 CATIA V5R20 / 5.20.0.9268 中文版）

| 结论 | 证据 |
| --- | --- |
| `StartCommand("Edge Fillet")`（**带空格**的英文 ID）能打开「倒圆角定义」对话框 | `docs/API探测/probe_command.log`；`"EdgeFillet"` 会弹"未知命令" |
| 对话框打开时，宏把边线 `Selection.Add` 进选择集，点「确定」真的会生成倒圆角 | 同日志：`Body.Shapes 1 -> 2` |
| 手动拾取的面的 `SelectedElement.Value` 是 `PlanarFace`，`Reference.DisplayName` 形如 `Selection_RSur:(Face:(Brp:(yz-plane);...))`，`GetCoordinates` 能给拾取点 | `run_assistant.py --check` 实测输出 |
| 边线的 `Reference.DisplayName` 是 `REdge:(Edge:(Face:(Brp:(Pad.1;0:(Brp:(Sketch.1;1)));...)))`，可读出"特征 + 草图元素序号" | `docs/API探测/probe_classify.log` |
| 草图元素序号 = `Sketch.GeometricElements` 里**排除"绝对轴"之后**的序号 | `probe_geom3.log` 与配对测试对照 |
| 草图坐标系 / 二维元素坐标能读（comtypes + `_midlSAFEARRAY(VARIANT)`） | `test_pairing_live.log`：`O=(0,0,0) U=(1,0,0) V=(0,1,0)`，四条边坐标正确 |
| `Shapes.GetBoundary(label)` 在 V5R20 上不可用；`Measurable.Length` 对 BRep 引用也不可用（对特征可用：Pad 体积 0.00024 m³） | `probe_labels.log` / `probe_geometry.log` |

## 3. 版本兼容性

用到的接口在 V5 里都是长期稳定接口，但**必须逐版本实测**，我给出分级说明：

| 接口 | 用途 | 说明 |
| --- | --- | --- |
| `Application.Documents/ActiveDocument/StartCommand` | 连接与启动命令 | V5R6+ 通用 |
| `Document.Selection` + `SelectedElement.Reference/Value/Type/GetCoordinates` | 选择集识别 | `Count2/Item2` 为 V5R16+ 推荐（更早版本用 `Count/Item`）；代码里已做兼容分支 |
| `Selection.FilterCorrespondence` | 官方"是否全是边"判定 | V5R7+ |
| `Part.CreateReferenceFromBRepName(label, ctx)` | 标签 → 可选对象 | V5R6+（官方示例 `CAAPriCreateEdgeFillet` 就是用它） |
| `Sketch.GetAbsoluteAxisData` / `GeometricElement.GetParamExtents/GetPointAtParam` | 草图几何 | V5 全系；**必须用 comtypes**，pywin32 传不了 `[in,out] SAFEARRAY(VARIANT)` |
| `Document.GetWorkbench("SPAWorkbench")` + `Measurable.GetCOG` | 求重心定对称中心 | V5R6+；取不到时退回草图包围盒中心 |
| 倒圆角对话框标题 | 识别命令 | 与语言/版本有关，`config.json` 可补 |

**旧版本（R14~R18 等）可能出现的问题与对策**

1. 对话框标题不同 → 在 `config.json` 的 `extra_dialog_titles` 里加（例如繁体「導圓角定義」）。
2. `StartCommand` 命令 ID 不同 → 用 `诊断.bat` 看命令是否打开；打不开就手工点 CATIA 工具栏，不影响"提醒"和"右键补线"。
3. 标签前缀可能略有差异（如无 `Cf8:()` 后缀、`MFBRepVersion_*` 不同）→ 解析用前缀+正则，不依赖后缀。
4. `Count2/Item2` 不存在 → 代码自动退回 `Count/Item`。
5. 32 位 CATIA → 需要 32 位 Python 环境（本机是 64 位，未验证）。

## 4. 已知限制

* **只支持草图生成的特征边线**：Pad/Pocket/回转体等，这是绝大多数需要倒圆角的边。
  圆角边、阵列生成的边、曲面边、布尔运算产生的边不在支持范围（会明确提示，不会乱补）。
* 对称中心取零件重心，要求零件本身关于该中面对称；非对称零件会提示"没有找到"。
* 一条边往往有多种对称解释，助手会让你选，不猜。
* 全局鼠标钩子会被个别安全软件关注；如被拦截，右键失效但热键仍可用。
* 助手通过 `GetActiveObject("CATIA.Application")` 附加到**已在运行**的 CATIA；不会自己启动 CATIA（`start_catia_if_missing` 预留）。

## 5. 二次开发入口

* 采集接口：`tools/dump_typelib.py`（把 CATIA 的 96 个 `*.tlb` 全量 dump 成文本，便于查接口拼写）
* 能力探测：`tools/probe_catia.py`（搜索语法/分类/几何/窗口/命令）、`tools/probe_geom3.py`（几何读取）、
  `tools/probe_measurable.py`（量测）、`tools/probe_dialog.py`（对话框控件）
* 联机回归：`tools/test_pairing_live.py`（对称配对的三种情形）、`tools/test_watcher_live.py`（误选提醒 + 补线 + 生成圆角）
