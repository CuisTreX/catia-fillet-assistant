# CATIA V5 倒圆角助手（DEV-2026-021）

给 CATIA V5 加两个"贴身"能力，解决倒圆角选边线的痛点：

1. **选到面立刻提醒**：打开「边线倒圆角」命令后，只要你（或宏）把面选进来，屏幕右上角立刻弹提醒，
   并能一键把误选的面从选择集里摘掉。
2. **右键补对称边线**：选中一条边线后**按鼠标右键**（热键 `Ctrl+Alt+R`），助手自动算出与它对称的那条边线，
   **并直接生成倒圆角**（半径取倒圆角对话框里的值，否则用配置默认值）。
   在倒圆角对话框里点选的边也支持：助手会读到它、算对称边、关掉对话框后直接出圆角。
   右键不会弹出 CATIA 原生菜单（想保留原生菜单可把 `rmb_mode` 改成 `dialog` 或 `off`）。
3. **形状级对称（v0.5.0，R5/R14）**：不再只看草图。助手会把**当前实体的所有边**扫出来，
   用几何自动识别镜像面，于是**圆角 / 阵列 / 布尔之后新生成的边**也能找对称边，
   并且支持**连续多刀**。核心能力（枚举边 → 量几何 → 拿真实引用直接建圆角）已在 V5R20 实测通过：
   100×60×40 凸台两条竖边 R5，体积 240000 → 239570.8 mm³；详见
   [docs/R5形状级对称-设计与实现.md](docs/R5形状级对称-设计与实现.md)。

> v0.5.1（性能与手感）：修掉"做过几次之后每次选线整圈边线变红、越用越卡"的问题
> （扫描会把整圈边放进选择集才能读——现在扫完会把**你原来的选择集原样还回去**，
> 动作结束后选择集清空）；平面评分加了必要条件的廉价预过滤与提前退出，
> 实测一次动作 **9s → 2.5s**（36 条边的零件），扫描 0.8s。

## 快速开始

### 方式一：便携版（推荐，拷过去就能用，不用装任何东西）

直接用 `dist\` 里的包，整个文件夹拷到目标机器，双击 exe 即可：

| 包 | 说明 |
| --- | --- |
| `dist\CATIA倒圆角助手-便携版\`（约 16 MB） | 单文件 exe，自带 Python/pywin32/comtypes |
| `dist\CATIA倒圆角助手-文件夹模式\`（约 33 MB） | 若封闭平台禁止 exe 从临时目录运行，用这个 |

到新机器先双击 `诊断.bat` 自检（会生成并弹窗显示诊断报告）。详见
[docs/便携版部署说明.md](docs/便携版部署说明.md)。

### 方式二：源码运行（开发用）

```
1) 双击「安装环境.bat」     # 首次运行，创建 venv 并安装 pywin32 / comtypes
2) 双击「启动助手.bat」     # 后台启动（无黑框）
3) 打开 CATIA，正常做倒圆角
4) 退出：在 CATIA 里按 Ctrl+Alt+Q
```

## 热键

| 热键 | 作用 |
| --- | --- |
| `Ctrl+Alt+R` | 给当前选中的边线补对称边线并直接生成倒圆角 |
| `Ctrl+Alt+X` | 移除选择集里误选的面/其它元素 |
| `Ctrl+Alt+F` | 打开「边线倒圆角」命令 |
| `Ctrl+Alt+Q` | 退出助手 |
| 鼠标右键 | 倒圆角对话框打开且选的都是边线时 = 补对称边线（并拦截右键菜单） |

## 已知限制（重要）

* 对称补线有**两套引擎**：草图引擎（老逻辑，靠草图元素编号 + 几何）和
  **形状级引擎**（v0.5.0，靠当前实体的边线几何）。形状级引擎覆盖圆角/阵列/布尔之后的新边；
  **不再需要 CAA**（原先"自动化无法枚举实体全部边"的结论是搜索语法用错了，已更正）。
* 一条边可能有多种对称解释（矩形零件：上下镜像 / 左右镜像 / 旋转 180° 都成立）。
  此时助手会弹窗让你选一种，而不是替你猜。
* 形状级引擎的"相邻面拓扑"判据暂时没用上（自动化拿不到"边→两侧面"，CAA 才有）；
  当前用位置+长度+半径+方向+中心距离代替，已通过 Case1/3/4/5 与不对称件负测试。
  与已有圆角几何冲突的新圆角会被 CATIA 拒绝：助手会清理半成品特征并提示，不会在模型里留废特征。
* 若某条边本身就在对称面上（镜像后还是它自己），助手会明确告诉你"它没有另一条镜像边"。
* 本机实测版本为 CATIA V5R20（5.20.0.9268 中文版）。换版本/换语言时，
  对话框标题可在 `config.json` 的 `extra_dialog_titles` 里补，命令 ID 见 `docs/技术方案与兼容性.md`。
  边线搜索语法可在 `shape_edge_queries` 里补。
* 做不到的事：在 CATIA 原生右键菜单里加菜单项需要 CAA RADE 二次开发授权，
  本项目用"全局右键钩子 + 自动化"替代，效果一致但不需要 RADE。

详细说明见 [docs/使用说明.md](docs/使用说明.md) 与 [docs/技术方案与兼容性.md](docs/技术方案与兼容性.md)。

## 兼容性（Win7 / 旧版 CATIA / 旧 Python）

* **Windows 7**：需要 Python **3.8.x**（Python 3.9 起官方不再支持 Win7）+ PyInstaller **4.10**。
  一键脚本：`安装环境-Win7-Python38.bat` → `打包便携版-Win7.bat`；
  依赖锁定在 `requirements-win7.txt`（comtypes 1.1.14 / pywin32 228）。
* **旧版本 CATIA**：版本相关信息全部可配置（`shape_edge_queries`、`catia_bin`、
  `extra_dialog_titles`、命令 ID），诊断报告会打印实际使用的搜索语法与命中条数。
* **旧版本 Python**：源码下限 3.8，`tools/check_compat.py` 静态校验（当前 56 文件 / 12184 行 0 问题）；
  3.13 开发环境同样全过。
* 详见 [docs/兼容性-Win7与旧版CATIA-Python.md](docs/兼容性-Win7与旧版CATIA-Python.md)。
